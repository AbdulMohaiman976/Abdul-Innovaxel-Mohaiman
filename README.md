# 🚀 URL Shortener API – Innovaxel Assignment

This is a take-home project for the ASE – Python Specialist position at Innovaxel.  
It allows users to create and manage short URLs via a RESTful API.

## ✅ Features

- Create short URLs
- Retrieve original URLs
- Update existing URLs
- Delete short URLs
- View statistics (access count)

## 🛠 Tech Stack

- Python 3.x
- Flask
- SQLite
